# 版本迭代归档

本目录保存 Ostium 各版本的方案、决策、审计、Review 台账和发布记录。当前发布事实、
测试门禁和残余 blocker 以 [`docs/release-status.md`](../docs/release-status.md) 为准；
面向用户的安装与升级说明在 [`docs/`](../docs/)。

> 历史文档中的路径、测试数字和发布状态是写作时点的记录，不随之后版本回填。
> 文件从仓库根目录移入本目录后，正文中以仓库根为基准的路径（例如
> `docs/release-status.md`、`CHANGELOG.md`）仍然按仓库根理解。
