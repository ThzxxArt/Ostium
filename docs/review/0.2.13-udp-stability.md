# Ostium 0.2.13 UDP 稳定性与可退化能力

> 主题：让 Hysteria2 这类 UDP 线路更稳定、更可诊断，并在抖动时可以退到 TCP。

## 1. 安装器自动调整 UDP 缓冲

`install.sh` 新增 `tune_udp_buffers`：

- 读取当前 `net.core.rmem_max` / `wmem_max`；
- 只升不降，写入 `/etc/sysctl.d/99-ostium-udp.conf`；
- 执行 `sysctl --system`；
- 安装和升级都会运行。

目标值默认 16 MiB。已手动设置更大的服务器不会被降低。

## 2. doctor / 线路健康

`ostium doctor` 新增：

```text
UDP buffers   PASS/WARN
Hysteria2     PASS/WARN/FAIL
```

- UDP 缓冲低于 8 MiB 时提示调整；
- Hysteria2 未监听、证书异常或缺少 salamander 时给出建议；
- 修复了未配置 TOTP 时 `Check` 参数错误。

「线路自检」页面继续显示每条线路的端口、证书、密钥和混淆状态。

## 3. Stable TCP 优先组

Clash / Mihomo 订阅新增：

```text
Ostium
  ├─ Auto
  ├─ Stable
  └─ 各线路
```

`Stable` 是 `fallback` 组，只包含 TCP 线路：

- VLESS Reality
- Trojan
- Shadowsocks 2022

不包含 Hysteria2。sing-box 订阅也新增同名 selector。

Hysteria2 抖动时，客户端切到 `Stable` 即可避免 UDP 线路。

## 4. 自动备份审计

worker 自动备份现在写入：

```text
backup.created  target=<filename>
backup.failed   detail={"error": ...}
```

「审计」页可以看到自动备份成功/失败，不再只能看「系统 → 最近备份」。
