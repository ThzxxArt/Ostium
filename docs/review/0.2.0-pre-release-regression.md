## 4. 真实 E2E 证据

本轮使用重新构建的 sing-box v1.14.4 重新执行真实 Trojan 自签 E2E：

```text
CURL_RC 0
BODY_PREFIX <!doctype html><html lang=en><head><meta charset=utf-8><link rel=icon href=data:
STATS {'e2e': (75, 933)}
PIN g0Ob/WAR7I1C6AUc
E2E_OK
```

- 临时数据目录，Trojan `0.0.0.0:8443`，自签证书 `localhost`；
- 客户端使用订阅生成的 `tls.certificate_public_key_sha256` 真实连接；
- 真实访问 `http://example.com/`，V2Ray stats 立即记录 `75` 上行 /
  `933` 下行字节。

超配额闭环沿用同一数据面的历史证据：

```text
PROXY_BODY=<!doctype html><html lang=en><head>...
E2E_USED=2016
QUOTA_STATE=False quota_exceeded 1008
QUOTA_SUB=403
E2E_OK
```

即：10 字节配额用户真实流量后被禁用，订阅返回 403。详见
[`docs/operations/e2e-evidence.md`](../operations/e2e-evidence.md)。

443 绑定仍受当前用户权限限制；本轮真实 E2E 使用 8443。
