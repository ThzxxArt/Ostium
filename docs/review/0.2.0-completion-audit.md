## 6. 外部阻塞（精确）

| 项 | 阻塞命令/原因 | 已完成的替代验证 |
|---|---|---|
| 443 绑定 | 当前用户 uid 1000，无 `CAP_NET_BIND_SERVICE`；`sudo` 需要密码 | 8443 真实代理 E2E；systemd unit 配置 capability |
| systemd 实机启动 | 本机无 `/opt/ostium` 安装、无 root；`systemd-analyze verify` 因宿主 permissions/缺少 sysinit 无法完成 | unit 语法/权限/路径逐行审查；shellcheck 通过 |
| Docker build/up | `docker: command not found` | Dockerfile/Compose 静态 YAML 校验；CI 配置 `docker compose config` |
| Caddy/certbot 运行 | 未安装 caddy/certbot，无 root 证书目录权限 | Caddyfile、pre/post/deploy hook 静态审查；shellcheck |
| PostgreSQL 18 | 本机无 PostgreSQL 服务 | CI test matrix 含 postgres；本地 SQLite 全量 |
| GitHub Actions | 需推送后由 GitHub 运行 | 本地同等命令全部通过；推送后等待 CI |
