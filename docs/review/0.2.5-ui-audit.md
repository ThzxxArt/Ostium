# Ostium 0.2.5 全页面 UI 审计

> 审计对象：`f3cfa04`（v0.2.5）
> 方式：Playwright 登录后逐页访问，1440 桌面 + 390 移动端截图；关键页
> 同时执行 axe。截图位于 `tests/ui/screenshots/`（本地生成，不进入 git）。

## 1. 修复的问题

| 页面 | 现象 | 根因 | 修复 |
|---|---|---|---|
| 设置 | 字段显示 `<django.forms.fields.CharField object at ...>` | 模板过滤器返回 `form.fields[key]`（未绑定 Field），不是 `form[key]`（BoundField） | 过滤器优先 `mapping[key]`；设置表单改为中文标签/帮助 |
| 设置 | 保存条悬浮遮挡字段 | `position: sticky; bottom: 16px` 覆盖表单 | 移到表单末尾，取消 sticky |
| 证书导入 | 页面与 Aurora 完全不一致、被 Admin 侧栏裁切、英文 | 从控制台跳到 Django Admin 自定义模板，并加载控制台 `app.css` 与 Unfold 冲突 | 新增控制台 `/certificates/import/`，使用 Aurora 模板；旧 Admin URL 302 到控制台 |
| 系统 | “期望版本/已应用版本 9”难以理解 | 直接展示内部修订计数，且用危险区红色边框 | 改为“配置应用状态 / 已同步 / 内部修订号”，加中文解释 |
| API 文档 | 页面空白 | Swagger UI 走 CDN + 内联脚本被 CSP 拦截 | 使用 `drf-spectacular-sidecar` 本地静态资源，并给内联脚本加 CSP nonce |
| Django Admin | 应用分组英文 | AppConfig verbose_name 为英文 | 账号/代理/证书/订阅/引擎/运维改为中文 |
| 用户详情 | 配额显示 `107374182400` | 表单 initial 使用原始字节数 | 显示 `100.0 GiB`；只有格式化会损失精度时才回退字节数 |
| 线路 | “No certificate / Assign a TLS certificate.” 英文 | 表单/模型校验消息英文 | 改为中文 |
