# Ostium 0.2.8 订阅链接修复

> 现象：用户详情页“显示完整链接”后，订阅 URL 与单节点 URI 超出卡片边界，
> 被 `overflow: hidden` 裁掉，无法查看或复制完整内容。

## 根因

1. `.copy-field code` 使用了 `white-space: nowrap` + `text-overflow: ellipsis`，
   长 URL 只显示一行并以省略号结尾。
2. 订阅面板 `.panel--accent` 使用 `overflow: hidden`，超出部分直接被裁切。
3. `.copy-field` 没有显式 `max-width` / `min-width: 0`，网格和 flex 子项
   按内容宽度撑开，复制按钮被推到可视区域外。
4. 异步 Clipboard API 被拒绝时，前端失败回调为空，既不提示也不回退。

## 修复

- 完整订阅链接和单节点链接改用 `.copy-field--wrap`：
  - `white-space: normal`
  - `overflow-wrap: anywhere`
  - `word-break: break-all`
  - `user-select: all`（单击即可全选）
- 链接框内增加带文字的“复制”按钮，按钮 `flex: none`，不会被长 URL 挤出。
- `.grid > *`、`.stack > *`、`.meta-chip` 增加 `min-width: 0`，允许内容收缩。
- 剪贴板失败时自动回退到 `document.execCommand("copy")`，不再静默失败。
- token 仍保持打码/省略显示，但保留复制按钮。

- 页面无横向滚动。
