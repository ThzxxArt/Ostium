# Ostium 0.2.10 客户端兼容性质量版本

> 目标：把“用户导入后才发现不通”的问题，变成 CI 中可重复发现的失败。

## 1. 真实客户端 E2E

新增 `tests/e2e/test_client_matrix.py`。测试启动：

- 本地 sing-box 服务端（高位端口，无需 root）；
- 本地 TLS 目标，用于 VLESS Reality 握手；
- 真实 Mihomo / sing-box / Xray 客户端；
- 通过 `https://example.com` 验证真实出网。

结果：

| 客户端 | VLESS Reality | Hysteria2 | Trojan | SS2022 |
|---|---|---|---|---|
| Mihomo v1.19.34 | PASS | PASS | PASS | PASS |
| sing-box v1.14.4 | PASS | PASS | PASS | PASS |
| Xray v26.11.9 | PASS | 不支持 | PASS | PASS |

CI 的 `e2e` workflow 新增 `clients` job，按路径触发并每日运行。

## 2. ProfileOptions

`renderers.py` 新增 `ProfileOptions`：

```python
ProfileOptions(
    dns_mode="client",       # client | system
    routing="cn-direct",     # cn-direct | global
    include_client_settings=False,
    include_geodata=False,
)
```

默认行为保持 0.2.9：

- 不写 DNS；
- 不写 `mixed-port` / `mode` / `ipv6` / `log-level`；
- 不依赖 MMDB / geosite；
- 只输出 `proxies`、`proxy-groups`、`rules`。

## 3. 订阅自检

命令行：

```bash
ostium subscription check --user alice
ostium subscription check --user alice --json
ostium subscription check --user alice --no-binaries
```

控制台：

- 「订阅」列表每行有自检按钮；
- 用户详情订阅面板有「兼容性自检」；
- 页面展示线路、Clash、sing-box、URI/Base64 结果；
- 服务器安装 `mihomo` / `sing-box` / `xray` 时执行真实配置校验。

## 4. 首次部署检查清单

总览页新增 6 项：

1. 创建第一个代理用户；
2. 启用至少一条线路；
3. 线路证书就绪；
4. 启用加密备份；
5. 配置告警 Webhook；
6. 启用两步验证。

未完成项显示「去处理」，全部完成后自动隐藏。
