{% icon "shield" %} 导入要求

证书必须是未过期的 PEM，SAN 或 CN 包含域名。域名留空时会自动从证书读取。

私钥必须与证书公钥匹配，且不能有密码保护。

证书和私钥只保存在服务端数据目录，权限收紧为 0600。

服务器路径仅允许 Ostium 的 /var/lib/ostium/imports，避免任意文件读取。

certbot 续期后，deploy hook 会自动调用 ostium cert sync。
