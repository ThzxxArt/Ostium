## P1 closed in this pass

- Rules: `rule_set`-only rules are unknown instead of matching everything; RE2-incompatible regex is rejected; `domain_suffix` uses label boundaries.
- SSRF: validated addresses are pinned into `socket.getaddrinfo` for the HTTP request, including redirect hops.
- API tokens: sensitive reads require `subscription:read`/`user:read`; write tokens retain full access.
- TOTP: a code that authenticated once cannot be replayed; setup confirmation can validate the same code once.
- Windows: UI data directory removes inherited access; Inno stops `OstiumCore` before replacing files.
- CLI: `init` is idempotent without `--force`; negative/empty sizes are rejected; self-signed cert issue binds and applies; backup create records a `Backup` row; status finds the core by name; service uninstall removes all four units.
- System proxy: repeated `enable` does not overwrite the saved original; `disable` without Ostium state does not clear a user's own Windows proxy.
- Database: migrations take a file lock and SQLite snapshot; failures restore the snapshot; `SCHEMA_HEAD` is checked against the Alembic graph.
- Frontend: exact quota round-trip, rule condition locking, subscription request race/error state, server-side log filtering, follow-on-scroll, WebSocket status, Public UI domain save, private key cleared after upload, token dialog cannot be dismissed accidentally, mobile drawer widths and safe-area top.
- Docs: release status, 0.1.1→0.1.2 upgrade, Nginx vs Public UI decision, 8443 health check, sudo/service-user commands, ACME generation names, unsigned/unsupported platform wording.
